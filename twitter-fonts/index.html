Fonts for Twitter / X

21 styles for a 50-character display name•checked, not guessed

What the app actually does with your text

A display name on X is 50 characters, and unlike the @handle it accepts whatever Unicode you give it. That makes the name field the most-styled piece of text on the platform and the one where the trade-off is sharpest: the styled name is the one people see, and the plain name is the one they can search for.

Posts are the easier case. At 280 characters there is room for a combining-mark style to double its cost without hurting, so strikethrough and underline stay on this list even though they are absent from the TikTok one. The character to watch is not the count but the reader's device.

Styles that paste cleanly (21)

Nothing here renders as a colour emoji and nothing here can form a flag. The notes name the Unicode block each style draws from, which is the honest predictor of how widely it renders.

What is deliberately missing

Regional indicator letters

Any adjacent pair that spells a country code becomes that country's flag, which in a display name happens more often than you would think.

Negative squared letters

🅰 🅱 🅾 🅿 hold the Unicode emoji property and are drawn in colour by the emoji font, so four letters break ranks with the rest of the name.

Squared letters

There is no lowercase set, so lowercase input quietly reuses the capitals, and the block is new enough that some devices have no glyph at all.

Greek-style symbol text

It contains a Hebrew נ and an Arabic ﻭ. Right-to-left characters reorder the text around them, and a reordered display name looks like a rendering bug.

Zalgo

It overflows into the line above, the character count is enormous against a 50-character name, and it is the one style most likely to be treated as abuse rather than decoration.

How this list was checked

The shortlist is derived, not asserted. For each style the transform was run across the whole alphabet and the output inspected for the Unicode blocks it uses, for characters carrying the emoji property, for regional indicators, and for right-to-left characters; the cost of an 18-character name was then measured in code points against the 50-character display-name limit. Anything that failed one of those checks is in the list below this table instead, with the reason attached. No part of this is a report of pasting every style into the live site on every device — that claim would be worth less than the arithmetic, because it could not be repeated.

The check itself is in the repository as tools/platform_check.js, and test/platform.test.js fails if this page ever lists a style the check rejects — so the table and its evidence cannot quietly drift apart.

Twitter questions

Will X let me change my display name to this?

The display name field accepts Unicode and caps at 50 characters, so yes, within that limit. The @handle is a separate field restricted to letters, numbers and underscores, and no styled character can go in it.

Why do people say styled names hurt your reach?

Not reach exactly, findability. Name search matches characters, so a styled name does not come up when someone types the plain spelling, and it will not autocomplete for people who half-remember it. The usual compromise is one styled word and the rest plain.

Does a styled post count differently against 280 characters?

The maths alphabets are one character each, so a styled word costs what it looks like. Combining-mark styles are the exception: each mark is its own character, so a struck-through word costs double. That is fine in a post and expensive in a name.

What happens in a quote or a screenshot reader?

Screen readers handle mathematical alphanumerics inconsistently, spelling them out, renaming them or skipping them silently. In a name that costs a listener a moment; in the body of a post it can cost them the sentence.
