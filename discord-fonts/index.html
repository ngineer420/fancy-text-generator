Fonts for Discord

25 styles that paste cleanly•and what markdown does to them

What the app actually does with your text

Discord is the friendliest of the four platforms here, because the desktop and mobile clients ship their own font stack rather than falling back to whatever the phone happens to have. Styles that come out as empty rectangles elsewhere generally render here, which is why this list is the longest of the four.

The complication is markdown. Discord parses asterisks, underscores, tildes, backticks and pipes in your message before it draws anything, and none of the styled alphabets contain those characters — so the styling itself passes through untouched. What does not is punctuation you typed yourself: an underscore either side of a word still turns it italic, and a stray asterisk still disappears. If your styled line needs literal asterisks, escape them.

What is deliberately missing

Regional indicator letters

Adjacent pairs that spell a country code render as that flag. Discord applies the same emoji rules as everywhere else.

Negative squared letters

🅰 🅱 🅾 🅿 have the emoji property, and Discord draws them from its emoji font — four coloured letters in the middle of a monochrome nickname.

Greek-style symbol text

It hides a Hebrew נ and an Arabic ﻭ, both right-to-left. In a channel name or a nickname the reordering is unpredictable and looks like a bug in your name.

Zalgo in a nickname

Twelve marks per character against a 32-character nickname limit is arithmetic that ends one way. In a message it is fine and it is what /glitch/ is for.

Combining marks in a nickname

They work, but each one is a whole character: an 18-character name written with a strikethrough costs 34 of your 32. The table says which styles those are.

How this list was checked

This list came out of running each transform over the full alphabet and inspecting the result rather than eyeballing a screenshot: which Unicode blocks the characters belong to, whether any of them carries the emoji property, whether any of them is a regional indicator, whether any of them is right-to-left, and what an 18-character nickname costs in code points once the style is applied. Discord's own constraints — the 32-character nickname cap and its markdown parsing — were then applied on top. That is the whole method, and it is the reason the notes are about blocks and character counts rather than vibes.

The check itself is in the repository as tools/platform_check.js, and test/platform.test.js fails if this page ever lists a style the check rejects — so the table and its evidence cannot quietly drift apart.

Discord questions

Will markdown break my styled text?

Not the styling itself. Discord's markdown triggers on asterisks, underscores, tildes, backticks and pipes, and none of the styled alphabets use those characters. Punctuation you typed yourself is still parsed normally, so escape any literal asterisks or underscores in the same message.

Can I use this in a server name or a channel name?

Server names take styled characters the same way nicknames do. Channel names are lowercased and have their own restrictions on punctuation, so styles that rely on capitals or on spacing are the ones that come out looking wrong there.

Why can nobody find me when they type my name?

Because the member search matches characters, and a Fraktur 𝔞 is not an a. Styling a nickname makes you harder to mention and harder to find; a common fix is a styled nickname with your plain name still in it, or plain text in your Discord profile bio.

Do these show up correctly on mobile?

Mostly, because the app carries its own fonts. The exceptions are the styles built from the newer astral blocks, which lean on the system font more heavily — those are the ones this table flags as Supplement rather than as an old BMP block.
